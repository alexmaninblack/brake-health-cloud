# Contributing

Use Node 26.0.0 and npm 11.12.1. Install only with `npm ci`, keep dependency
versions exact, and run typecheck, test, build and quality gates before review.
Do not add external adapters, credentials, operational data, generated output
or deployment material without a separately accepted work packet.
