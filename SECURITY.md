# Security

Do not commit or load keys, certificates, tokens, passwords, Unit identities or
Cloud credentials. The foundation binds development HTTP only to loopback and
contains fixture-only UI data. Report security issues privately to the project
owner rather than placing sensitive details in a public issue.
